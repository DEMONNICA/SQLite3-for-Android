> [!NOTE]
> ```
> Replaces system SQLite3 with an optimized build and auto-optimizes all system databases.
> ```

> [!IMPORTANT]
> Features ✨:
> 1. SQLite version `3.53.4 2026-07-24 19:02:57`
> 2. Supports `ARM64, ARMv7a, x86, and x86_64` architectures.
> 3. Removes leftover files from uninstalled apps.
> 4. Optimizes all system databases automatically.
> 5. Trims unused storage blocks to extend lifespan.

> [!TIP]
> 1. Supports `AxManager` and their forks — `Non-Root or Root`.
> 2. Supports `APatch` `KernelSU` `Magisk` and their forks.
> 3. Minimum Android `10 SDK 29`.
> 4. This module requires a **Hybrid Mount** module to enable system binary overlay support — [Download Meta](https://github.com/Hybrid-Mount/meta-hybrid_mount/releases) or any compatible alternative.
